# docs/decisions/ — Mimari Karar Kayıtları (ADR)

Bu dizin, enyxma projesinin yaşam döngüsü boyunca alınan tüm kritik mimari kararları (ADR formatında) barındırır.
Her kararın bağlamı, değerlendirilen alternatifler, varılan sonuç ve gerekçeleri açıkça belgelenir.
Ajanlar veya geliştiriciler değişse bile sistemin mimari tutarlılığı bu kayıtlar üzerinden korunur.
